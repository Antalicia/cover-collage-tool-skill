# 封面拼图工具 · Claude Skill

> 一句话让 Claude 生成电商/课程/社媒封面拼图，输出 1500×2000px PNG，全程浏览器运行，无需安装任何软件。

---

## 简介

这是一个用于 [Claude.ai](https://claude.ai) 的 **Skill 插件**。安装后，当你告诉 Claude "帮我拼封面图" 或上传 PPT 截图时，Claude 会自动交付一个本地 HTML 工具，你在浏览器中上传图片、填写标题，点击导出即可得到成品。

**工具完全离线运行**，图片数据不会上传到任何服务器。

---

## 效果预览

生成图片的版式结构（1500 × 2000 px）：

```
┌─────────────────────┐
│                     │  ← 封面头图（700px）
│      封面头图        │     PPT 首页截图，contain 模式保留比例
│                     │
├─────────────────────┤
│      页面标题        │  ← 标题栏（250px）
│                     │     字号自动适配（40~120px）
├──────────┬──────────┤
│  页面 1  │  页面 2  │  ← 其他页面网格（1050px）
├──────────┼──────────┤     张数自动决定列数（1~4 列）
│  页面 3  │  页面 4  │
└──────────┴──────────┘
```

## 安装方式

1. 下载本仓库中的 [`cover-collage-tool.skill`](./cover-collage-tool.skill) 文件
2. 打开 [Claude.ai](https://claude.ai) → **Settings → Skills**
3. 点击上传，选择 `.skill` 文件
4. 安装完成 ✅

---

## 使用方式

安装后，在 Claude 对话中直接说：

> "帮我生成一张封面拼图"
> "我有几张 PPT 截图，帮我拼成封面图"
> "生成一张课程封面"

Claude 会自动识别意图，将工具文件发给你，附带使用说明。

---

## 工具功能说明

打开 HTML 工具后，左侧面板依次操作：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 选择背景色 | 5 种快捷色块，或自定义拾色器 |
| 2 | 填写页面标题 | 最多 30 字，字号自动缩放适配 |
| 3 | 上传封面头图 | 建议用 PPT 首页截图，1 张 |
| 4 | 上传其他页面 | 可多选，自动排列网格 |
| 5 | 点击导出 | 生成 `封面图_时间戳.png` |

右侧为**实时预览**，每次修改即时更新。

---

## 网格列数规则

底部图片区域会根据上传数量自动决定布局：

| 图片数量 | 列数 |
|---------|------|
| 1 张 | 1 列 |
| 2 ~ 4 张 | 2 列 |
| 5 ~ 9 张 | 3 列 |
| 10 张以上 | 4 列 |

所有图片均以 **contain 模式**展示（完整显示、不裁切，留白处填充背景色）。

## 自定义修改

如果你想调整版式，直接编辑 `assets/封面拼图工具.html` 顶部的常量：

```javascript
const CANVAS_W = 1500;  // 画布宽度
const CANVAS_H = 2000;  // 画布高度
const COVER_H  = 700;   // 封面图区域高度
const TITLE_H  = 250;   // 标题区高度
// 底部网格高度 = CANVAS_H - COVER_H - TITLE_H（自动计算）
```

**常见改法：**

- 不需要标题：将 `TITLE_H` 改为 `0`，标题框留空即可
- 横版（4:3）：`CANVAS_W = 2000`，`CANVAS_H = 1500`，同步更新 HTML 中的 `<canvas>` 标签属性

## 技术说明

- 纯原生 HTML + Canvas API，无任何外部依赖
- 图片处理全部在本地浏览器完成，不联网
- 支持拖拽上传、多选上传
- 导出使用 `canvas.toBlob()` + 临时 `<a>` 标签，兼容主流浏览器
